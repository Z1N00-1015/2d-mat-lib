# Beyond Silicon — 2D 물질 연구 분야 안내

2차원 물질, 결정학·분석법, 반도체 물리와 소자 응용의 주요 개념과 연구 분야를 소개하는 웹사이트입니다. 시각 자료와 브라우저 실험(LAB)을 함께 제공합니다.

🌐 https://z1n00-1015.github.io/2d-mat-lib/

## 구성

- `index.html` — 표지: 전체 분야와 각 분야의 목차
- `chapters/<분야>/<장>.html` — 분야 소개 페이지 (사이드바 목차, LAB, 정리, 이전/다음 페이지)
- `assets/js/book-runtime.js` — 분야·페이지 목록(`FIELDS`)과 공통 레이아웃, 실험 모듈 지연 로딩
- `assets/css/book.css` — 디자인 시스템 (SemiBook과 같은 계열, 라이트/다크 테마)
- `assets/js/*.js` — 실험 모듈 (three.js, Canvas)
- `data/papers.json` — 연구실 논문 DB 공개용 데이터
- `data/paper-focus.json` — 논문별 핵심 소재. 등록 논문이 추가되면 이 파일에 논문 ID와 핵심 소재를 함께 추가합니다. 보조 재료와 기판은 자동으로 핵심 소재에 포함하지 않습니다.

논문 분석실 로그인 링크도 사이드바와 도구 분야 표지에서 열 수 있습니다.

## 새 분야 추가하기

1. `assets/js/book-runtime.js`의 `FIELDS` 배열에 분야(`id`, `title`, `chapters`)를 추가합니다.
2. `chapters/<분야 id>/` 폴더에 장 페이지를 만듭니다. 기존 장 페이지를 복사해 `data-field`, `data-chapter`와 본문만 바꾸면 됩니다.
3. 표지, 사이드바, 이전/다음 장 링크는 `FIELDS`에서 자동으로 만들어집니다.

## 논문 데이터

`data/papers.json`은 Mac의 로컬 논문 DB에서 생성합니다. 분석실에서 바뀐 내용을 `DB_저장.command`로 비공개 `lab-paper-library` 저장소에 저장하면, 이 저장소의 GitHub Actions가 5분마다 DB를 읽어 서지정보와 검토 완료 데이터만 내보내고 GitHub Pages를 갱신합니다. Actions 탭에서 `Sync research paper database`를 수동 실행할 수도 있습니다. 원문 인용, AI 요약, 검토 대기 값과 PDF는 공개 JSON에 포함되지 않습니다.

이 동기화에는 `2d-mat-lib` 저장소의 Actions secret `LAB_PAPER_LIBRARY_READ_TOKEN`이 필요합니다. 이 토큰은 비공개 `lab-paper-library` 저장소를 읽기만 합니다. 로컬 DB를 저장한 뒤 보통 5분 안에 새 데이터가 사이트에 배포됩니다.

## 로컬 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

시뮬레이션은 개념 이해를 위한 단순화 모델이며, 물성 수치는 문헌의 대표값입니다.
