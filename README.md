# Beyond Silicon — 차세대 반도체 물질

원자 한 층 두께의 2D 물질(그래핀, h-BN, MoS₂, WSe₂ …)과 넓은 밴드갭 반도체(SiC, GaN, Ga₂O₃, 다이아몬드)를
**결정학 인터랙티브 실험**으로 배우는 교육용 웹 콘텐츠입니다. 애플 홈페이지 스타일의 스크롤형 단일 페이지입니다.

## 인터랙티브 실험

| # | 실험 | 내용 |
|---|------|------|
| 01 | 양자 터널링 | 게이트 절연막(SiO₂ / HfO₂ / hBN) 두께에 따른 파동함수 투과 |
| 02 | 단채널 효과 | 자연 길이 λ, 장벽 저하, I<sub>d</sub>–V<sub>g</sub> 곡선 (Si vs MoS₂ vs WSe₂) |
| 03 | 3D 결정 구조 뷰어 | 그래핀, h-BN, 2H-MoS₂, Si, GaN, 4H-SiC, CsPbI₃ — 슈퍼셀·층 수·단위 셀 |
| 04 | 브라베 격자 · 역격자 | 2D 격자 5종 분류, 역격자 벡터, 위그너–자이츠 셀, 제1 브릴루앙 영역 |
| 05 | 밀러 지수 | (hkl) 결정면 가족, 면간 거리, 면 위 원자 (SC/BCC/FCC) |
| 06 | 브래그 법칙 · XRD | 경로차 애니메이션, 구조 인자 기반 분말 XRD 패턴과 소멸 규칙 |
| 07 | 모아레 | 트위스트 각·격자 불일치에 따른 모아레 초격자, 매직 앵글 |
| 08 | 밴드갭과 빛 | 광자 에너지 ↔ 파장 ↔ 흡수 물질 |
| 09 | MoS₂ 층 수 | 간접 → 직접 밴드갭 전이와 광발광 |
| 10 | 디랙 콘 | 벌집 격자 강결합 밴드 3D + Γ–M–K–Γ 경로 |
| — | 전력 반도체 | 밴드갭–절연파괴 전계 버블 차트, BFOM 비교 |
| — | 스카치테이프 박리 | 흑연 박리 게임, 285 nm SiO₂ 위 광학 대비 |
| — | CVD 성장 | 핵생성·성장·결정립계, 에피택셜 정렬 |

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

three.js(r160)는 `assets/vendor/`에 포함되어 있습니다.
