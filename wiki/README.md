# 위키 문서 폴더

이 폴더의 `*.md` 파일 하나가 사이트의 위키 문서 하나가 됩니다. 파일 이름(영문 소문자·하이픈)이 주소가 됩니다. 예: `mos2.md` → `chapters/wiki/mos2.html`

## 새 문서 만들기

1. 비슷한 문서(예: `mos2.md`)를 복사해 새 이름으로 저장합니다.
2. 맨 위 `---` 사이의 항목을 채웁니다. `title`, `category`, `summary`는 꼭 필요합니다.
   - `category`: 물질 · 결정학 · 전자 구조 · 물성 · 공정 · 분석법 · 소자 · 연구 분야 · 기타
   - `status`: 초안 / 검토됨 (사람이 원문과 대조해 확인한 문서만 `검토됨`)
   - `sources`: `- 표시할 이름 | 주소` 형식, 한 줄에 하나
   - `info`(물질 문서의 정보 상자): `- 항목 | 값` 형식
3. 본문은 마크다운으로 씁니다. 다른 문서는 `[[문서 제목]]` 또는 `[[문서 제목|보여 줄 글자]]`로 잇습니다. 아직 없는 문서는 빨간 글자로 표시되고 전체 문서 목록의 "아직 없는 문서"에 모입니다.
4. 확인: `python3 tools/build_wiki.py` 후 `python3 -m http.server 8000`, http://localhost:8000/chapters/wiki/ 를 엽니다.

## 원칙

- 모든 사실과 수치에 출처를 답니다. 확인하지 않은 값은 넣지 않습니다.
- 그림은 직접 그린 것이나 CC BY 등 사용이 허락된 것만 씁니다.
- 논문 원문 문장을 길게 옮기지 않고, 미공개 데이터·개인 정보를 넣지 않습니다.
- `chapters/wiki/`와 `data/wiki-index.json`은 자동으로 만들어지는 파일이라 직접 고치지 않습니다.
