소자·합성 벤치마크

인용 논문에 명시된 2D 소재의 소자 성능과 합성 조건을 원문 DOI와 함께 비교합니다.

5.4.1데이터를 읽는 방법

각 행은 논문에 보고된 하나의 결과 또는 측정 조건을 나타냅니다. 같은 논문에 여러 온도 조건이 있으면 별도 행으로 둡니다. 측정 구조와 조건이 서로 다르므로, 숫자만으로 소재 간 성능 순위를 매기지 마세요.

빈 셀은 값이 확인되지 않았거나 해당 결과와 연결되지 않은 항목입니다. TODO는 원문을 더 확인해 추가할 항목을 뜻합니다. 수치는 원 논문에서 확인된 값만 수록했습니다.

5.4.2이동도와 발표 연도

이동도가 원문에서 수치로 확인된 결과만 표시합니다. 조건과 소자 구조는 점을 선택하거나 가리켜 확인하세요.
